# 待機中の点のアニメーション

2026-09-12、ユーザー指定で待機中の3点を左から順に跳ねさせる。回答者・閲覧者、PC・Mobileで共通のAnswerMemoへ追加する。

既存の点の字体・色・配置と「待機中」の文言は保ち、各点をCSS transformで上へ0.18em動かす。周期は1.2秒、2点目は150ms、3点目は300ms遅らせる。レイアウトを動かす処理やJavaScriptタイマー、依存パッケージは追加しない。

点は装飾として読み上げ対象外のままにする。OSの「視差効果を減らす」などでprefers-reduced-motionが有効な場合は静止表示にする。

TypeScriptの型チェックが成功。Chromiumの1280px・390px幅で各点の頂点が左→中央→右の順になることと、reduced-motionで静止することを確認した。
