# 全員退出時の自動中断

2026-09-12、ユーザー指定で手動中断を廃止。`session.abort`コマンド、確認UI、ヘッダーの中断ボタンを採用しない。同名ユーザーの補助表示も追加しない。FigmaのP06・P10・P11は不採用として非表示にした。

最後のWebSocketが切れたら、Discord Activity Instance APIで退出を確認する。usersが空、またはinstanceが404で消滅している場合のみ、進行中セッションをABORTEDにし、新しいLOBBYを一つのトランザクションで作る。APIを待つ間に誰かが再接続した場合とsessionIdが変わった場合は中断しない。

APIの403・429・5xxやネットワーク障害は全員退出の証拠とみなさない。再確認は60秒周期。これにより一時切断・再読み込み・サーバー再起動ではゲームを継続できる。旧セッションの保存期限は退役から24時間、無人roomの削除は24時間のまま。

開発用認証にはDiscord instanceがないため、WebSocketが0本になってから15秒の再接続猶予を置き、保守周期で自動中断する。この開発時の近似と、本番のDiscord退出確認は区別する。

実際のSQLiteを使い、全socket切断だけでは継続、API障害でも継続、Discordの空users確認で旧セッション終了・新LOBBY作成を検証した。
