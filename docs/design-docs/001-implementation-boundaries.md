# 実装境界と作業順序

2026-09-12 / ユーザー指定を反映。

サーバーを実装・検証した後、Figmaにある表示部品を先に実装し、その部品を組み合わせてPC画面、Mobile画面を作る。共通部品はゲーム通信を直接扱わない。

**Figmaに定義されていない文言・視覚部品は追加しない。** 既存設計書の補助画面・トースト・接続メッセージ・空状態説明・独自の確認文・PIP案内の提案より、この指定を優先する。不足する状態はワークアラウンドで隠さず、Figmaに補助UIを提案してから実装する。サーバーのエラーコードをそのまま画面へ出さない。必要なDOMの意味付けや非表示の状態管理は実装する。

表示名・投稿内容・人数・問題番号などは、Figmaの定義された欄へ実データを渡す。デモの人名や正解を本番へ埋め込まない。Tablerへの置換は既に指定された採用表を使う。

Figma参照: PC `3:2`、Mobile `127:16`、共通部品ページと[画面契約](../DESIGN_CONTRACT.md)。機能ごとの判断・制約・検証結果はこのディレクトリへ追記する。

追記: ユーザーの最終指定により手動中断は不要。全員退出で自動中断する。P06/P10/P11は不採用。同名ユーザーを区別する補助表示も追加しない。[全員退出時の設計](004-empty-activity.md)を優先する。
